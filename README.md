## 📌 Overview

This repository contains my solutions to the **~120+ coding problems** featured in the **MountBlue Technologies HackerRank Challenge**. 

The MountBlue Job Challenge assesses core Data Structures, Algorithms, and logical problem-solving skills across easy-to-medium difficulty levels.
